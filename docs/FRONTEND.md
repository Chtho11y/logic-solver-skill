# Penpa 工作区

使用真正的本地 Penpa+ 编辑器。来源与许可见 `web/public/penpa-edit/VENDOR.md` 和 `NOTICE`。

## 界面与操作

页面由左侧变量总览、中间 Penpa 工作区和右侧 DSL 编辑器组成。
变量总览列出所有已定义变量、绘制元素及值域，并支持切换变量、逐项显隐和全部显隐。
每个变量只占一行，右侧是一组图标切换按钮：眼睛控制整个变量，铅笔控制题目线索，对勾控制求解叠加结果，
聚焦框"仅显示"隔离该变量，再次点击恢复全部。关闭的分项显示为灰色斜杠。
标题栏右侧的两个眼睛图标用于全部显示和全部隐藏。
Penpa Solution 模式绘制的手工答案单独列出。全部隐藏包括手工答案；全部显示恢复所有分项。
显隐不改变数据、撤销历史或求解约束。
盘外线索和预设区域边界单独列出。窄屏时总览排列在画布上方。
每个变量显示题目标记数量。切换"绘制到"只影响新笔画，不会移动已有内容。
清空、求解、导入预设、样例、链接导入及尺寸/参数控件通过 React portal 放入 Penpa 原生工具区。
桌面工具栏居中排列为两行：第一行是预设、样例、清空、求解和原生操作；第二行是直接可见的链接导入、尺寸、参数及后端。
所有按钮高度和边框一致，窄屏自动换行。状态提示单独显示。

变量行末尾的“⋯”打开编辑窗口，可修改名称、整数值域和说明，或删除变量。
改名保留笔画、颜色、撤销历史和显隐状态，并同步更新 DSL 同名标识符、图层及样例绑定；注释、字符串和成员属性名不变。
删除前需在窗口内确认；删除该变量及其笔画，不自动删改规则，需手动处理 DSL 中遗留的引用。
变量类型和绘制元素在此窗口只读，更换类型可另建变量。

在 Penpa 选择绘制模式后，Mode 下方显示水平排列的"绘制到"按钮：

- 列出绑定到当前元素的变量，包括预设中的变量；数字模式同时显示盘外线索，边线模式显示区域边界。
- 按钮沿用 Penpa Mode 行的 `label_mode`/`label` 样式，选中态也相同（灰底加橙色描边）；同一元素可以属于多个变量。
- "新增变量"可设置名称、待求解/题目线索类型及整数值域。边线模式还可新增区域划分变量。
- 新建后立即选中该变量，并切换到 Problem 模式；下一笔直接写入该变量，不会落入手工答案。
- 未绑定时画下的内容会在首次新增变量时归入该变量；未绑定内容仍存在时，求解明确报错。
- 各变量分别保存原生题目标记、颜色和撤销/重做记录。同一格可以给不同变量填不同值。
- 多变量同时显示时当前变量优先显示；切换变量查看重叠内容及其求解结果。

## 预设与自定义规则

DSL 编辑器高亮关键字、字符串、数字、注释及函数调用。输入标识符会自动提示，
也可用 Ctrl+Space 触发补全；↑↓ 选择、Tab/Enter 接受、Esc 关闭。
补全菜单采用类似 VS Code 的紧凑样式：每项占一行，依次为类型图标、名称（高亮已输入前缀）、参数和来源；
底部详情栏显示当前选中项的签名及说明。菜单显示在光标旁，随滚动调整位置，底部空间不足时向上展开。
支持当前变量、局部 let/for 名称、builtin、当前函数及已导入规则库的函数；import 字符串中可补全库名。
这是基于词法和声明的补全，不进行完整类型推断，错误定位仍由求解器返回。
"Doc 文档"打开可搜索的语法规则、Builtin 函数签名/说明和规则库源码。
语法及库直接来自仓库，builtin 来自后端 `/api/builtins`，避免维护第二份函数清单。

初始为自定义工作区，无需选择题型即可新增变量、编写 DSL 并求解。
"导入预设"是显式载入操作，会替换工作区的变量、规则和样例。仅更改下拉选项不会修改盘面。
导入后仍可新增变量、修改 DSL 和组合规则函数；预设不限制可用元素或变量。
导入多个预设不会自动合并规则；组合规则需要编辑 DSL，并配置其所需变量。

清空盘面保留变量定义、规则、尺寸和参数；"载入样例"重新填入最近预设的样例。
链接导入写入当前变量，保留其他变量；尺寸不同时使用原生尺寸迁移同步调整所有变量。
盘外段长列表与阴阳题白/黑圈编码在转换中保留。

## 求解与数据边界

前端提交当前可编辑 `spec`、DSL、参数及各变量独立的 Penpa URL 给 `/api/solve`。
后端检查变量定义，分别解码、绑定，再共同构建求解模型；仍兼容原有只提交题型实例的接口。
新增变量的类型、值域和图层映射实际参与求解，不是显示标签。
区域划分变量上画出的边线转成该变量的边界约束。

求解答案仅在绘制时叠加，不覆盖手工答案或历史记录。盘面、变量、参数或 DSL 改动使旧结果失效，
重复快捷键不会重复提交。导出保留原生撤销/重做及回放历史。解码器报告不支持的内容时显示错误。

原生分享 URL 只包含当前变量的题目标记和手工答案，不包含完整工作区或自动求解叠加层；
截图包含可见内容。目前尚无完整工作区的保存/加载入口，刷新前需自行保存 DSL。
特殊 Penpa 标记仍受解码器能力限制；部分题型规则仍不完整，SAT 不等于所有原始规则已验收。

## 精简与验证

隐藏重复的新建/导入、克隆、背景图片、数独专用导入及原生约束菜单；保留绘制、手工答案、
撤销、变换、截图及分享。保留原版初始化依赖的 DOM 和库，宿主侧栏仅负责变量总览。

- `npm --prefix web test`：参数往返。
- `npm --prefix web run test:browser`：真实 Penpa 输入、双变量隔离、独立撤销、尺寸迁移、
  自定义规则、预设后追加变量、实际后端求解、延迟响应及桌面/窄屏布局。
- `python -m unittest discover -s tests`：包括自定义工作区绑定、定义校验和区域边界约束。
- `npm --prefix web run build`：类型检查与生产构建。
