# Penpa 工作区

使用真正的本地 Penpa+ 编辑器。来源与许可见 `web/public/penpa-edit/VENDOR.md` 和 `NOTICE`。

## 界面与操作

页面只有 Penpa 工作区和右侧 DSL 编辑器。没有独立操作顶栏或左侧图层栏。
清空、求解、导入预设、样例、链接导入及尺寸/参数控件通过 React portal 放入 Penpa 原生工具区，沿用其按钮样式。
尺寸与参数、链接导入收在可展开菜单中。

在 Penpa 选择绘制模式后，Mode 下方显示水平排列的“绘制到”按钮：

- 列出绑定到当前元素的变量，包括预设中的变量；数字模式同时显示盘外线索，边线模式显示区域边界。
- 点击变量切换当前输入目标，选中按钮高亮；同一元素可以属于多个变量。
- “新增变量”可设置名称、待求解/题目线索类型及整数值域。边线模式还可新增区域划分变量。
- 未绑定时画下的内容会在首次新增变量时归入该变量；未绑定内容仍存在时，求解明确报错。
- 各变量分别保存原生题目标记、颜色和撤销/重做记录。同一格可以给不同变量填不同值。
- 多变量同时显示时当前变量优先显示；切换变量查看重叠内容及其求解结果。

## 预设与自定义规则

初始为自定义工作区，无需选择题型即可新增变量、编写 DSL 并求解。
“导入预设”是显式载入操作，会替换工作区的变量、规则和样例。仅更改下拉选项不会修改盘面。
导入后仍可新增变量、修改 DSL 和组合规则函数；预设不限制可用元素或变量。
导入多个预设不会自动合并规则；组合规则需要编辑 DSL，并配置其所需变量。

清空盘面保留变量定义、规则、尺寸和参数；“载入样例”重新填入最近预设的样例。
链接导入写入当前变量，保留其他变量；尺寸不同时使用原生尺寸迁移同步调整所有变量。
盘外段长列表与阴阳题白/黑圈编码在转换中保留。

## 求解与数据边界

前端提交当前可编辑 `spec`、DSL、参数及各变量独立的 Penpa URL 给 `/api/solve`。
后端检查变量定义，分别解码、绑定，再共同构建求解模型；仍兼容原有只提交题型实例的接口。
新增变量的类型、值域和图层映射实际参与求解，不是显示标签。
区域划分变量上画出的边线转成该变量的边界约束。

求解答案仅在绘制时叠加，不覆盖手工答案或历史记录。盘面、变量、参数或 DSL 改动使旧结果失效，
重复快捷键不会重复提交。导出保留原生撤销/重做及回放历史。解码器报告不支持的内容时显示错误。

原生分享 URL 只包含当前变量的题目标记和手工答案，不包含完整工作区或自动求解叠加层；
截图包含可见内容。目前尚无完整工作区的保存/加载入口，刷新前需自行保存 DSL。
特殊 Penpa 标记仍受解码器能力限制；部分题型规则仍不完整，SAT 不等于所有原始规则已验收。

## 精简与验证

隐藏重复的新建/导入、克隆、背景图片、数独专用导入及原生约束菜单；保留绘制、手工答案、
撤销、变换、截图及分享。保留原版初始化依赖的 DOM 和库，移除闲置宿主侧栏及适配代码。

- `npm --prefix web test`：参数往返。
- `npm --prefix web run test:browser`：真实 Penpa 输入、双变量隔离、独立撤销、尺寸迁移、
  自定义规则、预设后追加变量、实际后端求解、延迟响应及桌面/窄屏布局。
- `python -m unittest discover -s tests`：包括自定义工作区绑定、定义校验和区域边界约束。
- `npm --prefix web run build`：类型检查与生产构建。
