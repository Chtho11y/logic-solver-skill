# 前端交互与实现边界

中央画布使用真正的 Penpa+（本地 vendored iframe），保留原生 Mode / Sub / Style、
输入、撤销/重做、变换及分享功能。来源、版本与许可见 `web/public/penpa-edit/VENDOR.md` 和根目录 `NOTICE`。
旧 SVG 画布及其渲染、几何、输入模块已移除。

## 布局

没有页面级顶栏。原顶栏操作全部归入中央 `penpa-ui` 工作区：

```text
┌──────────┬────────────────────────────────┬─────────────────┐
│ 已用图层 │ 题型 / 尺寸 / 参数 / 后端      │ 规则 DSL        │
│ 显隐开关 │ 样例 / 链接导入 / 清空 / 求解  │ 重置 / 行号     │
│          │ 状态与错误                    │ 编译错误定位    │
│          │ Penpa+ 原生工具与 canvas      │                 │
│          │ 规则说明                      │                 │
└──────────┴────────────────────────────────┴─────────────────┘
```

900px 以下规则区移到下方；560px 以下各区纵向排列。错误和导入提示可换行。
左侧只显示已使用图层，点击可切换 Penpa 模式。显隐操作按 Penpa 底层字段分组：
例如格内数字和盘外数字共用 number 字段，目前不能完全独立隐藏。

## 数据与操作

- Penpa 是当前盘面的权威来源；`drawing.ts` 用于样例、导入和求解绑定，不替代原生编辑状态。
- `PenpaPane.tsx` 和 `studio-bridge.js` 连接 iframe；`bind.ts` 负责元数据及参数转换。
- 样例及链接解码后写入新建的 Penpa 棋盘。调整尺寸使用 Penpa 原生坐标迁移，保留实时输入。
- 换题型保留非空盘面；空盘可自动加载样例。“样例”按钮明确覆盖盘面。
- 实例参数优先于题型默认值，并按所属题型隔离。摩天楼缺少显式 k 时按列数推导；
  Easy as ABC 和 Fuzuli 不根据列数猜测 k。中央可修改数字/字母种数、星数等数值参数。
- 清空保留尺寸和题型参数。未识别题型的链接可以先导入，再选择规则绑定。
- 导入/求解仅支持解码器可识别的图层；并非所有 Penpa 原生标记都能转换为 DSL 输入。

## 求解一致性

求解从实时 Penpa 盘面导出 URL，经 `/api/import` 解码并绑定，再提交 `/api/solve`。
隐藏题目图层仍参与导出；宿主参数与解码后的盘外线索分别保留。
修改盘面内容、参数或 DSL 后，旧结果失效；相同标记数量但不同内容也会被检测。
返回结果只有在宿主版本和原生盘面版本都匹配时才显示。按钮与 Ctrl+Enter 共用防重复检查。
空白 DSL 原样提交，由后端报告错误。点击原生画布会接收键盘焦点，包括重建棋盘之后。

## 验证

- `npm --prefix web test`：参数往返及跨题型隔离。
- `npm --prefix web run test:browser`：真实 Penpa iframe、原生输入及撤销/重做、
  隐藏线索导出、尺寸迁移、延迟响应失效、答案回填、桌面与窄屏布局。
  链接解码使用实际 Python 实现；求解响应由测试控制以稳定重现竞态。
- `npm --prefix web run build`：类型检查与生产构建。
