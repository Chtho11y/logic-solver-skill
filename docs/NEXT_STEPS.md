# 下一步实施计划

更新：2026-09-28。基础是当前真正的 Penpa+ 工作区；继续优先修复数据正确性和交互问题。
第 1 阶段的基础闭环及第 3 阶段的布局调整已实现，并增加浏览器真实求解回归；其余内容仍为计划。

## 1. Penpa 输入到答案回填（基础闭环已完成）

- 逐项核对数字、涂色、符号、边线、连线、区域和盘外线索的映射；先修复连线/边线答案无法正确回填的问题。
- 检查多值盘外线索、区域及特殊标记在导入、调整尺寸、导出中的损失；不支持的内容明确提示。
- 分开处理原生手工答案与求解结果，防止失效清理误删用户答案。
- 细分图层显隐，避免隐藏格内数字同时隐藏盘外数字；显隐、撤销和再次求解不应丢失线索。

已完成：原生渲染叠加答案、手工历史保护、格内/盘外数字及符号独立显隐、区域边界、多值线索与阴阳编码转换，以及无关入口精简。
已补充同类元素的各变量独立显隐；剩余：特殊标记映射。

验收：选用数字、涂色、回路和区域四类代表题，执行真实 Penpa 输入 → 实际后端求解 → 原生答案显示；
核对导出后的线索及参数。保留延迟响应竞态测试，增加手工答案保护和各类答案回填回归。

## 2. 加强已有规则的正确性证据

- 为上一阶段代表题补充固定答案、非法解反例和第二解检查。
- 按使用频率补齐 21 个缺少随附样例的题型，逐项复核 35 个标注部分实现的题型。
- 文档分别记录文件覆盖、样例通过与规则缺口，继续避免把 SAT 等同于规则完整。

验收：新增案例说明来源及预期；非法解被拒绝，声明唯一的案例无第二解。
状态统计由生成器更新并通过 `--check`。

## 3. 改善中央工作区使用体验

- 增加题型名称/别名搜索；保持居中的紧凑工具区，尺寸和参数直接可见。
- 优化窄屏原生工具区滚动及提示，确保样例、导入、求解和撤销操作可达。
- 左侧变量总览、中间 Penpa+、右侧 DSL；清空、求解和预设导入位于原生工具区，变量选择位于绘制工具下方。

已完成：移除独立操作边栏、统一原生按钮样式、居中的两行工具区、直接可见的链接与尺寸参数、按绘制元素横向选择或新增变量。
变量总览支持改名、值域和说明编辑，以及带确认的删除操作。
预设导入后允许新增变量和编辑规则；同类元素的不同变量具有独立线索与撤销历史。
剩余：预设搜索、完整工作区保存与恢复（包含全部变量和 DSL）；原生分享链接目前只保存当前变量及手工答案。

验收：桌面、平板、手机宽度下均能完成选题、输入、撤销、求解流程；页面无横向溢出，关键状态可见。

## 4. 求解任务隔离与语言服务

Web DSL 已提供词法高亮、基础声明补全及文档查询。下一步将阻塞求解迁移到可取消的独立任务，
支持超时、取消和错误恢复；再接入完整 Web DSL 语言服务及类型感知补全。
扩展剩余题型安排在上述基础能力稳定之后。

验收：长时间求解期间其他请求可响应；取消或超时后无遗留任务、无过期结果；
Web 诊断与现有 VS Code 服务共用规则与位置转换。

建议下一次实施第 2 阶段，优先为已打通的代表题补充非法解反例和唯一性检查。
