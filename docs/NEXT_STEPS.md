# 下一步实施计划

更新：2026-09-28。基础是当前真正的 Penpa+ 工作区；继续优先修复数据正确性和交互问题。
以下为待办计划，不代表已实现。

## 1. 完成 Penpa 输入到答案回填的闭环（最高优先级）

- 逐项核对数字、涂色、符号、边线、连线、区域和盘外线索的映射；先修复连线/边线答案无法正确回填的问题。
- 检查多值盘外线索、区域及特殊标记在导入、调整尺寸、导出中的损失；不支持的内容明确提示。
- 分开处理原生手工答案与求解结果，防止失效清理误删用户答案。
- 细分图层显隐，避免隐藏格内数字同时隐藏盘外数字；显隐、撤销和再次求解不应丢失线索。

验收：选用数字、涂色、回路和区域四类代表题，执行真实 Penpa 输入 → 实际后端求解 → 原生答案显示；
核对导出后的线索及参数。保留延迟响应竞态测试，增加手工答案保护和各类答案回填回归。

## 2. 加强已有规则的正确性证据

- 为上一阶段代表题补充固定答案、非法解反例和第二解检查。
- 按使用频率补齐 21 个缺少随附样例的题型，逐项复核 35 个标注部分实现的题型。
- 文档分别记录文件覆盖、样例通过与规则缺口，继续避免把 SAT 等同于规则完整。

验收：新增案例说明来源及预期；非法解被拒绝，声明唯一的案例无第二解。
状态统计由生成器更新并通过 `--check`。

## 3. 改善中央工作区使用体验

- 增加题型名称/别名搜索，将尺寸和低频参数收进可展开区，给原生画布更多空间。
- 优化窄屏原生工具区滚动及提示，确保样例、导入、求解和撤销操作可达。
- 保留当前三栏和无页面顶栏布局，避免重新实现一套画布工具。

验收：桌面、平板、手机宽度下均能完成选题、输入、撤销、求解流程；页面无横向溢出，关键状态可见。

## 4. 求解任务隔离与语言服务

先将阻塞求解迁移到可取消的独立任务，支持超时、取消和错误恢复；再接入 Web DSL 高亮与语言服务。
扩展剩余题型安排在上述基础能力稳定之后。

验收：长时间求解期间其他请求可响应；取消或超时后无遗留任务、无过期结果；
Web 诊断与现有 VS Code 服务共用规则与位置转换。

建议下一次实施只覆盖第 1 阶段，形成一个可独立验收的改动。
