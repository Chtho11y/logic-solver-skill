# DSL 语言服务：当前状态与待办

此文件替代早期实施计划；已完成项目不再列作待开发。安装与设置见
[VS Code 扩展说明](../editors/vscode/README.md)。

## 已实现

- `puzzle/lsp/rpc.py`：标准库 JSON-RPC / stdio 传输。
- `workspace.py`、`index.py`：文档同步、符号索引、导入解析。
- `server.py`：初始化、语义高亮、诊断、悬浮、定义跳转、文档和工作区符号、
  补全、签名帮助、引用查找及配置更新。
- `convert.py`：UTF-16 / UTF-32 位置转换。
- `editors/vscode/`：TextMate 基础高亮、客户端启动及配置。
- `tests/lsp/`：协议、编码转换、索引、高亮、诊断、悬浮、跳转和进程端到端测试。

语法诊断无需求解器；语义诊断需要可用建模依赖，以及同名题型 JSON 和样例。
库文件缺少实例上下文，只提供语法诊断。解析器遇首个错误即停止，当前不保证多错并报。

## 维护边界

语言服务使用轻量语法索引，不用执行求解器来回答悬浮或跳转。
词法器、语法树和位置变动时，要同时回归 Unicode 坐标与编辑中不完整源码。
编译器的名称可见性变动应同步检查索引；不能只检查正常源码的高亮。
